# موبایل هشتگ | Mobile Hashtag — فروشگاه اینترنتی گوشی و لوازم جانبی

فروشگاه اینترنتی کامل، فارسی و راست‌چین برای فروش گوشی موبایل، لوازم جانبی و کالای دیجیتال؛
همراه با پنل مدیریت فارسی، ۲۷ کالای نمونه، ۱۴ دسته اصلی، بنرها، مجله و تسویه‌حساب نمایشی.

## اجرای سریع

```bash
npm install
npm run dev      # اجرای محلی روی http://localhost:5173
npm run build    # خروجی production در dist/
npm test         # اجرای ۵۴ تست خودکار
```

پیش‌نیاز: Node.js 18+‎. هیچ سرویسی (دیتابیس/بک‌اند جدا) لازم نیست.

## حساب‌های نمایشی

| نقش | موبایل | رمز |
|---|---|---|
| مدیر (پنل `/admin`) | 09120000000 | admin123 |
| مشتری | 09121111111 | 123456 |

## امکانات

- صفحه اصلی با ۱۴ بخش قابل مدیریت (اسلایدر، دسته‌بندی، منتخب، شگفت‌انگیز، گوشی‌ها، لوازم، هدفون، پرفروش‌ها، تازه‌ها، بنرها، برندها، چرا ما، مجله، خبرنامه)
- فروشگاه با فیلتر (دسته/برند/قیمت/موجودی/تخفیف)، ۵ مرتب‌سازی، صفحه‌بندی و جستجو
- صفحه محصول: گالری با زوم، تنوع (رنگ/حافظه)، مشخصات فنی، نظرات، کالای مرتبط
- سبد خرید، تسویه‌حساب (نمایشی)، پیگیری سفارش، علاقه‌مندی‌ها، حساب کاربری
- پنل مدیریت: داشبورد، محصولات، دسته‌ها، برندها، سفارش‌ها، بنرها، صفحه اصلی، مشتریان، نظرات، مقالات، قالب، تنظیمات
- همه تصاویر (محصول/دسته/برند/لوگو) به‌صورت لوکال در `public/images` — بدون وابستگی خارجی
- فونت وزیرمتن به‌صورت لوکال (بسته `@fontsource/vazirmatn`)

## ساختار

```
src/
  models/      مدل‌های داده (مطابق مفاهیم ووکامرس)
  data/        سید اولیه: محصولات، دسته‌ها، برندها، بنرها، مقالات، سفارش‌ها
  services/    دیتابیس (db)، سبد/کاربر (shop)، اعلان (toast)، فرمت فارسی
  components/  سربرگ، پاصفحه، کارت محصول، اسلایدر، اجزای مشترک
  pages/       ۲۰ صفحه فروشگاه
  admin/       پنل مدیریت (۱۲ بخش)
  styles/      سیستم دیزاین (base/store/admin)
public/images/ محصولات، دسته‌ها، بنرها، برندها، لوگو (SVG + PNG)
tests/         تست منطق + رندر همه مسیرها + جریان‌های تعاملی
docs/          معماری، ساختار داده، راهنمای تبدیل به وردپرس، گزارش تست
scripts/       تولید تصاویر (gen:art) و ممیزی لینک/تصویر
```

## ⚠️ محدودیت‌های نسخه نمایشی (مهم)

- **پرداخت واقعی فعال نیست**؛ تسویه‌حساب نمایشی است و در خود صفحات هم اعلام شده.
- **ذخیره‌سازی با localStorage مرورگر** است، نه دیتابیس چندکاربره امن (جزئیات: `docs/ARCHITECTURE.md`).
- **ورود نمایشی** است و امنیت واقعی ندارد؛ رمزها با هش نمایشی ذخیره می‌شوند.
