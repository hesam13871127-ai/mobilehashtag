# هویت بصری و دارایی‌های محلی

## اصول

سفید غالب، طلایی `#C9A44C`، طلایی روشن `#E7D29A`، طلایی عمیق، متن تیره و فضای خالی کنترل‌شده. نشان اختصاصی یک قاب تلفن و علامت هشتگ است؛ لوگو فقط متن نیست. متن‌های تبلیغاتی فارسی در HTML واقعی قرار دارند تا خوانا، قابل ترجمه، قابل جست‌وجو و واکنش‌گرا باشند؛ هیچ متن فارسی به شکل bitmap روی تصویر چسبانده نشده است.

همه فایل‌ها داخل `frontend/assets` هستند. هیچ URL موقت، hotlink یا تصویر placeholder استفاده نمی‌شود.

## فایل‌های برند

`images/brand/`:

- `symbol.svg`: نشان اصلی موبایل/هشتگ، برداری.
- `logo-horizontal.svg`: نسخه افقی نشان و نام انگلیسی برند.
- `mobile-logo.png`: خروجی شفاف ۱۹۲ پیکسلی نشان.
- `frontend/favicon.png`: favicon واقعی PNG، ۶۴ پیکسل.
- شش گرافیک تایپوگرافیک برای معرفی برندهای محصول: apple، samsung، xiaomi، sony، anker، jbl. این‌ها بازنمایی تایپوگرافیک نام برند برای پیمایش‌اند، نه فایل رسمی لوگو یا ادعای نمایندگی.
- لوگوی فارسی header ترکیب نشان SVG و نام فارسی با فونت Vazirmatn است.

## بنرهای بزرگ (۴ کمپین)

| کمپین | فایل | کاربرد / CTA |
|---|---|---|
| یک قدم جلوتر، با دنیای تکنولوژی | `banners/hero-phone.webp`, `hero-phone-wide.webp` | گوشی‌ها؛ عریض برای desktop و نمای اصلی برای mobile |
| دنیای بیرون خاموش، موسیقی تو روشن | `banners/audio.webp` | هدفون؛ اسلایدر و کمپین صدای صفحه اصلی |
| زمان به سبک تو | `banners/watch.webp` | ساعت هوشمند |
| همیشه متصل، همیشه پرانرژی | `banners/power.webp` | پاوربانک |

## بنرهای کوچک (۴ کمپین)

- `banners/airpods.webp`: ایرپاد؛ «کوچک، اما شگفت‌انگیز».
- `banners/case.webp`: قاب؛ «محافظت، با سلیقه شما».
- `banners/charger.webp`: شارژر؛ «سریع‌تر شارژ شو».
- `banners/speaker.webp`: اسپیکر؛ «یک صدا، هزار خاطره».

این فایل‌ها ترکیب‌بندی تبلیغاتی با تصویر محصول، بافت، سایه و عناصر هندسی دارند؛ مستطیل رنگی خالی نیستند. CTA و تیتر در قالب قرار دارند.

## محصولات و گالری‌ها

۱۰ محصول اصلی با تصاویر جداگانه:

1. `iphone.webp`
2. `samsung.webp`
3. `xiaomi.webp`
4. `airpods.webp`
5. `headphones.webp`
6. `powerbank.webp`
7. `charger.webp`
8. `case.webp`
9. `watch.webp`
10. `speaker.webp`

برای هر کلید، فایل `-detail.webp` نیز وجود دارد. **این تصویر دوم برش بزرگ‌نمایی‌شده همان تصویر اصلی است، نه عکس زاویه مستقل**؛ در UI هم «نمای جزئیات» نام دارد.

تصاویر تکمیلی SVG/WebP برای cable، glass، lens، holder، memory، flash، tablet، pen، gamepad، tracker، strap، earbuds، adapter و تصاویر اختصاصی گوشی‌های poco/honor/redmi و مچ‌بند band ساخته شده‌اند. بعضی دسته‌های سازگار یا محصولات کابل یک تصویر خانوادگی مشترک دارند؛ ۱۰ محصول اصلی هر کدام تصویر مستقل دارند.

## دسته‌ها و مقالات

- ۱۲ فایل در `images/categories/` برای مسیرهای اصلی خرید، بهینه‌شده در ۲۴۰ پیکسل.
- همه ۴۷ رکورد category نیز یک مسیر تصویر مناسب در دیتابیس دارند.
- ۳ تصویر در `images/blog/` برای راهنمای گوشی، هدفون و باتری.

## منشأ و محدودیت استفاده

- تصویر اصلی hero و ۹ تصویر اصلی محصول با ابزار تولید تصویر AI همین پروژه ساخته شده‌اند. سقف ابزار در این نوبت ۱۰ تولید بود.
- اسپیکر و تجهیزات تکمیلی، تصویرسازی SVG اختصاصی‌اند؛ منبع آن‌ها در پروژه وجود دارد.
- بنرهای دیگر، thumbnailها و نمای جزئیات از ترکیب همین دارایی‌ها با اسکریپت‌های محلی ساخته شده‌اند.
- این‌ها **عکس مستند محصول واقعی یا عکس رسمی سازنده نیستند**. تطابق دقیق شکل دوربین، درگاه، رنگ یا جزئیات سخت‌افزاری تضمین نمی‌شود؛ قبل از فروش واقعی، عکس و مشخصات باید با موجودی فروشنده تطبیق داده شوند.
- نام تجاری و ظاهر محصولات برای شناسایی کاتالوگ نمونه استفاده شده‌اند. هیچ ادعایی درباره تأیید سازندگان، مالکیت علائم تجاری یا نمایندگی مجاز وجود ندارد. بررسی مجوز و علامت تجاری برای انتشار تجاری بر عهده بهره‌بردار است.
- فونت Vazirmatn از بسته `@fontsource/vazirmatn` و فونت نشانه‌ها از `@fontsource/noto-sans-symbols-2` آمده است. هر دو محلی و تحت SIL OFL هستند؛ متن مجوز در `assets/fonts/` همراه بسته است.

## بازتولید خروجی‌ها

```text
npm ci
npm run assets
```

این فرمان SVGها، WebPها، گالری جزئیات، فونت‌ها، خروجی‌های نشان و بنرها را از منابع محلی می‌سازد. PNGهای اولیه AI در ZIP هستند. هیچ تماس جدید با سرویس AI لازم نیست. تولید دوباره مقاله‌ها/تصاویر دسته، قیمت و داده سفارش را تغییر نمی‌دهد.
