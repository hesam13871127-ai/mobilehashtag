## بازبینی بصری و اصلاحات

تصاویر مرورگر صفحه اصلی در desktop/mobile و checkout موبایل بررسی شدند. بنر عریض اصلاح شد تا دوربین و بدنه گوشی در desktop برش نامناسب نداشته باشند. برای فلش‌های ناوبری از SVG استفاده شد تا وابسته به فونت سیستم نباشند. محصولات تکمیلی پوکو/آنر/ردمی/مچ‌بند تصویرسازی مستقل گرفتند.

در آماده‌سازی تست، Chromium حالت single-process مانع ایجاد context دوم می‌شد؛ این flag در تنظیم آزمون حذف شد. دو انتظار داده‌ای fixture نیز با کاتالوگ واقعی اصلاح شدند. همه مجموعه‌ها پس از اصلاحات از ابتدا اجرا و نتایج نهایی بالا ثبت شده‌اند؛ اجرای ناموفق اولیه به‌عنوان موفق گزارش نشده است.

## مرز این گزارش

- روی **Windows، Safari، Firefox، دستگاه فیزیکی یا شبکه واقعی موبایل** اجرا نشده است؛ اندازه viewport در Chromium شبیه‌سازی شده است.
- Lighthouse، تست بار/فشار، ممیزی WCAG کامل، penetration test مستقل و تست استقرار production انجام نشده‌اند.
- درگاه پرداخت، پیامک، ایمیل، ارسال فیزیکی و بازگشت واقعی کالا وجود ندارند و آزمون موفق برای آن‌ها ادعا نشده است.
- داده‌ها، موجودی، قیمت‌ها و نظرات seed نمونه‌اند؛ این تست‌ها صحت قیمت بازار یا مشخصات تولیدکننده را تأیید نمی‌کنند.
- هشدار experimental SQLite در Node 22 مشاهده شد؛ مانع اجرای هیچ آزمون نبود.

## آزمون بسته مستقل ZIP

ZIP در پوشه‌ای **جدا از checkout پروژه** استخراج شد. موارد زیر واقعاً انجام شدند:

1. کنترل CRC تمام فایل‌های archive و نبود `.env`، دیتابیس مشتری، `.git` و `node_modules` در بسته.
2. اجرای `npm ci --omit=dev` در پوشه استخراج‌شده: نصب موفق ۷۸ بسته runtime، audit بدون مورد گزارش‌شده.
3. اجرای `npm run setup`: ساخت `.env` با کلید جدید و دیتابیس تمیز.
4. اجرای سرور از سورس استخراج‌شده روی پورت موقت و دریافت موفق صفحه اصلی و `/health`.
5. دریافت ۲۸ محصول و ۴۷ دسته از API همین نسخه استخراج‌شده.
6. ثبت حساب تازه، افزودن قاب به سبد و ثبت سفارش آزمایشی واقعی در SQLite با مبلغ **۵۵۹٬۰۰۰ تومان** (۴۹۰٬۰۰۰ کالا + ۶۹٬۰۰۰ ارسال نمونه).
7. کنترل وضعیت `demo_confirmed` و توقف تمیز سرور آزمون.

نتیجه: **موفق روی Linux**. این آزمون از فایل‌های پروژه اصلی یا node_modules آن استفاده نکرد. آزمون اجرا روی Windows همچنان انجام نشده است.
