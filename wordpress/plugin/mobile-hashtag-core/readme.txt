=== Mobile Hashtag Core ===
Requires at least: 6.5
Requires PHP: 8.1
Stable tag: 1.0.3
License: GPL-2.0-or-later

Installable release; see docs/KNOWN-LIMITATIONS.md and the accompanying QA reports.
Independent store/contact settings, persisted customer messages, newsletter consent,
admin search/status/CSV/delete, WordPress privacy integration, server-side wishlist,
and resumable public-catalog migration into official WooCommerce.

Install from Plugins > Add New > Upload. Activate official WooCommerce separately.
Follow docs/INSTALL-FA.md and docs/MIGRATION-FA.md. No automatic currency conversion.
No customers/passwords/orders/private messages or fictional reviews are imported.
No destructive uninstall: theme switching or plugin deletion does not wipe customer messages.
Newsletter is storage/consent management, not an email campaign delivery service.

Code: GPL-2.0-or-later, see LICENSE.txt. Catalog imagery is preserved from the supplied
MOBILE HASHTAG source; this package does not assert new ownership or merchandising rights.
No WordPress/WooCommerce core, runtime/database, credentials or paid plugin is bundled.
