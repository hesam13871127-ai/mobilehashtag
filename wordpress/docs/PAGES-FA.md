# برگه‌های واقعی نسخهٔ 1.0.2

اینها post type واقعی `page` هستند، نه URL ظاهری یا فایل HTML خارج از وردپرس. برگه‌ها در اولین بازدید مدیریتی پس از فعال‌شدن قالب/Core ایجاد می‌شوند و از دکمهٔ راه‌اندازی نیز قابل بررسی/ترمیم‌اند. شناسه‌ها متناسب با هر نصب متفاوت‌اند.

| برگه | slug | نقش |
|---|---|---|
| خانه | home | صفحهٔ نخست ایستا؛ نشانی عمومی `/` |
| فروشگاه | shop | `woocommerce_shop_page_id` و آرشیو واقعی محصولات |
| درباره هشتگ | about | معرفی کامل با طرح about-hero، متن و تصویر محلی واردشده |
| تماس با ما | contact | اطلاعات مرکزی + فرم واقعی ذخیره در پیشخوان |
| پیگیری سفارش | tracking | `[woocommerce_order_tracking]` |
| حساب کاربری من | my-account | `woocommerce_myaccount_page_id` و `[woocommerce_my_account]` |
| سبد خرید | cart | `woocommerce_cart_page_id` و فرم بومی WooCommerce |
| تکمیل سفارش | checkout | `woocommerce_checkout_page_id` و تسویه بومی |
| شرایط خرید و بازگشت | terms | `woocommerce_terms_page_id` و متن قابل ویرایش |
| حریم خصوصی | privacy | `wp_page_for_privacy_policy` و متن قابل ویرایش |
| مجله هشتگ | blog | `page_for_posts` و آرشیو نوشته‌های واقعی |
| حساب کاربری قدیمی | account | سازگاری با مسیر قبلی؛ shortcode حساب |
| ورود | login | فرم بومی ورود در چیدمان مرجع |
| ثبت‌نام | register | فرم بومی حساب؛ فعال‌سازی ثبت‌نام در تنظیمات WooCommerce لازم است |
| علاقه‌مندی‌ها | wishlist | `[mh_wishlist]`، ذخیرهٔ سمت سرور |
| پرسش‌های متداول | faq | محتوای قابل ویرایش |

۱۱ صفحهٔ ضروری و ۵ صفحهٔ تکمیلی/سازگاری = **۱۶ برگه**. برگهٔ نمونهٔ پیش‌فرض WordPress، برگهٔ حریم خصوصی پیش‌نویس هسته، یا صفحات قبلی مشتری حذف نمی‌شوند.

## سیاست حفظ اطلاعات

- تنظیم صفحات خالی/نامعتبر خودکار تکمیل می‌شود؛ تغییر اتصال معتبر قبلی نیازمند تأیید گزینهٔ اتصال در راه‌اندازی است.
- محتوا/عنوان برگهٔ موجود حفظ می‌شود؛ پیش‌نویس همنام گزارش خطا می‌دهد تا مدیر دربارهٔ انتشار تصمیم بگیرد.
- تنها با تأیید گزینهٔ اتصال، بلوک رسمی Cart/Checkout به shortcode رسمی تبدیل می‌شود؛ اصل محتوا در `_mhc_classic_backup_102` ذخیره و سایر بلوک‌ها حفظ می‌شوند.
- تغییر slug برگهٔ شناخته‌شده باعث ساخت نسخهٔ تکراری نمی‌شود؛ لینک‌ها از شناسه و permalink واقعی وردپرس ساخته می‌شوند.
- منوهای قبلی با لینک سفارشی خارج از سایت خودکار ویرایش نمی‌شوند. منوهای تولیدشده در نمایش ← فهرست‌ها قابل مدیریت‌اند.

فهرست شناسه‌ها و permalinkهای واقعی نصب آزمایشی در `reports/v1.0.2/setup-safety.txt`، بررسی HTTP صفحات و لینک‌های هدر/فوتر در `reports/v1.0.2/onboarding.json` قرار دارد. نشانی دامنهٔ آزمایش وابستگی محصول نیست؛ نصب مشتری از دامنهٔ خود وردپرس استفاده می‌کند.
